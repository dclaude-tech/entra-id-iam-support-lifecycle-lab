# IAM User Access Troubleshooting and Lifecycle Support Lab | Microsoft Entra ID

## Overview

This project is a hands-on IAM support lab built in Microsoft Entra ID.

The goal of this lab is to practice realistic entry-level IAM Analyst work, including sign-in review, new hire access support, mover access cleanup, leaver account cleanup, and audit access validation.

This is a fictional portfolio lab using simulated tickets and fictional users. The users, groups, access matrix, and ticket scenarios are not real, but the workflows are based on practical IAM support tasks.

## Lab status

In progress.

## Planned scenarios

- MFA sign-in review
- New hire missing baseline access
- Mover access cleanup
- Leaver account cleanup
- Audit access validation
